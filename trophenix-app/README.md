# Trophenix

## Project Structure

### `backend/`
Django REST API backend with Docker configuration, database migrations, and API endpoints for athlete management and confidence tracking.

### `frontend/`
React-based web application built with Bun, providing the user interface for the Trophenix platform.

### `terraform/`
Infrastructure as Code using Terraform to manage AWS resources including RDS, VPC, ECR, and App Runner services.

### `data/`
Data & IA project
